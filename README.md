# GregCasting
*Sufficiently advanced technology is industinguishable from magic.\
Sufficiently explored magic becomes technology.*

GregCasting is a Minecraft mod that aims to connect the mods [Hex Casting](https://github.com/FallingColors/HexMod/), [GregTech Modern](https://github.com/GregTechCEu/GregTech-Modern) and [Applied Energistics 2](https://github.com/AppliedEnergistics/Applied-Energistics-2), both functionally and lore-wise.

Development is currently in progress for Minecraft 1.20.1, and development for 1.21.1 will resume once GregTech has become sufficiently up-to-date and stable.

This branch collects resources to be used across versions.
